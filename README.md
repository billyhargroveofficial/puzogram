# puzogram

Terminal Telegram client — React Ink UI + GramJS MTProto. Catppuccin Mocha theme, chat folders, archive tab, mouse support.

## Run

```sh
export TG_API_ID=... TG_API_HASH=...  # https://my.telegram.org
npm install
npm run dev
```

## Demo (100% fake data)

```sh
npm run demo -- 1  # main view: group chat with bubbles
npm run demo -- 2  # Personal folder + typed draft
npm run demo -- 3  # Archive tab
```

Quit the demo with Ctrl+C, like the real app.
